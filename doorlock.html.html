How it works


    

  • The 8086 reads 4 key presses from the keypad (through 8255 PPI Port A) and stores them in memory buffer INPUT using SI and a CX counter.
    • 

  • It compares INPUT with the stored PASSWORD using REPE CMPSB. If ZF = 1 the PIN matches.
    • 

  • Correct PIN: 8255 Port C bit 0 = 1, the relay energises, the door unlocks, and it auto-locks after 5 seconds.
    • 

  • Wrong PIN: TRIES is incremented. After 3 wrong attempts the buzzer (Port C bit 1) sounds and the system locks for 10 seconds.
    • 

  • 8255 addresses: Port A = 00H, Port B = 02H, Port C = 04H, Control = 06H. The code runs in emu8086 as well (keyboard via INT 21H).
